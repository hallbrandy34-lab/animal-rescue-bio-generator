# AI Adoption Bio Generator

This is my first project for my AI Software Engineering degree.  
It's a simple Python script that generates short, adoptable bios for rescue animals.

## How it works
You enter:
- the pet's name
- the species (dog, cat, etc.)
- a list of personality traits

The script creates a friendly adoption bio that rescues can use in posts or listings.

## Example
Input:
- Name: Daisy
- Species: dog
- Traits: gentle, playful, great with kids

Output:
"Meet Daisy! This sweet dog is gentle, playful, great with kids. Daisy is looking for a loving home where they can feel safe, cared for, and finally get the happy ending they deserve."

## Why I built this
I love animals and rescue work, so I wanted my first project to be something meaningful and helpful.
